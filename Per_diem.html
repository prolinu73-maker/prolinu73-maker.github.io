자동 조회 연결

요금은 공공데이터포털(국토교통부 TAGO)에서 가져옵니다. 웹 화면이 포털에 직접 물어볼 수 없어서, 중간에서 대신 물어봐 주는 "중계 서버"를 한 번 만들어 연결합니다.

이 탭은 관리자 모드(주소 끝에 #admin)에서만 보입니다. 위 칸에 저장한 주소는 이 브라우저에만 남습니다. 모든 접속자가 자동 조회를 쓰게 하려면, 이 HTML 파일을 메모장으로 열어 RELAY_URL='' 의 따옴표 안에 주소를 넣고 저장한 뒤 그 파일을 올리세요.

처음 연결하는 순서

  1. 인증키 받기. 공공데이터포털(data.go.kr)에서 아래 4개에 각각 활용신청을 하고, 마이페이지에서 인증키를 복사합니다.
    국토교통부_(TAGO)_고속버스정보 · 시외버스정보 · 열차정보 · 국내항공운항정보
  2. 중계 서버 만들기. script.google.com 에서 새 프로젝트를 만들고, 편집 칸을 비운 뒤 Code.gs.txt 내용을 전부 붙여 넣습니다.
  3. 인증키 넣기. SERVICE_KEY 줄의 따옴표 안에 인증키를 붙여 넣고 저장합니다.
  4. 시험하기. 함수 선택 칸에서 test를 고르고 실행합니다. 실행 로그에 요금이 나오면 성공입니다.
  5. 배포하기. 배포 → 새 배포 → 웹 앱, 액세스 권한 모든 사용자로 배포하고 웹 앱 URL을 복사합니다.
  6. 연결하기. 그 URL을 위 칸에 붙여 넣고 저장합니다.

시외버스는 포털이 당일 배차 정보만 제공하므로 오늘 날짜 기준 요금이 나옵니다. "※요금 확인 필요"가 붙은 기차 요금은 코레일 요금과 비교해 주세요. 올 때 요금은 도착일 기준으로 반대 방향을 따로 조회합니다. 조회 결과가 없는 교통수단은 예비 요금표 값을 대신 씁니다.

예비 요금표

자동 조회가 안 될 때만 쓰는 표입니다. 들어 있는 요금은 예시 값이며, 실제 요금으로 고친 뒤 상태 칸을 누르면 "확인됨"으로 바뀝니다. 노선이 없는 교통수단은 0으로 둡니다.
